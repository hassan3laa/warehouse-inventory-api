# Warehouse Inventory API

A RESTful API for managing warehouse products, categories, suppliers, and inventory.

## Features

- User authentication and authorization
- Admin and employee roles
- Product CRUD operations
- Category CRUD operations
- Supplier CRUD operations
- Product search
- Filtering
- Sorting
- Pagination
- Field limiting
- Input validation
- Password hashing
- Rate limiting
- Secure HTTP headers
- Centralized error handling

## Technologies

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- Validator.js
- Helmet
- express-rate-limit
- HPP
- CORS
